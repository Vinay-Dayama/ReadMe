## 🚀 Featured Projects

### 🎯 AI-Based Career Guidance System

An AI-powered web application developed as an academic mini project that provides personalized career guidance based on a user's educational and professional background.

The system allows users to identify themselves as:

* 🎓 Student
* 📚 Undergraduate
* 💼 Working Professional

Based on the selected category, users answer a personalized questionnaire. Their responses are then structured into a prompt and processed using a Large Language Model to generate personalized guidance.

The generated results include:

* 🎯 Suitable career recommendations
* 🧠 Reasons behind the recommendations
* 🛣️ Suggested career roadmaps
* 📚 Skills to develop
* 💰 Salary insights
* 🚀 Career progression guidance

**Technologies Used:** Python • HTML • CSS • JavaScript • LLM APIs
